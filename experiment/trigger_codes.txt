AVMoments-EEG: Acquisition Trigger Codes
======================================

Scope
-----
These definitions describe the triggers generated by
run_experiment.py.

Video category triggers
-----------------------
Each video trial receives a category trigger after the first display flip
in its playback loop. The code identifies the category and whether an
attention-check question is scheduled after the video.

Without an attention check: trigger = category number (1-16).
With an attention check:    trigger = category number + 100 (101-116).

Rest request
------------
Trigger 66 is sent when Space is detected during video playback. It marks
a request for a rest, not an immediate pause of the movie. The rest screen
appears after the movie and any scheduled attention-check question.

Parallel-port output
--------------------
The configured parallel-port address is 0x3EFC. Each call to send_triggers
sets the port to the requested code, waits for 0.01 seconds by default,
and resets it to 0. Zero is the reset value, not a separate trial category.
The 10 ms value is the requested software pulse duration; hardware timing
has not been validated as part of preparing this documentation.
